# Bloom Bouquet — Web & Mobile Application

Bloom Bouquet is a web and mobile application developed to support an online bouquet ordering business. The platform provides customers with a convenient way to browse products, place orders, and make digital payments, while enabling administrators to manage products, orders, and customer information.

## Project Overview

Bloom Bouquet consists of two main components:

- **Mobile Application:** Provides customers with access to product catalogs, shopping carts, favorites, checkout, payments, and order information.
- **Admin Web Application:** Enables administrators to manage products, categories, orders, customer information, notifications, and sales reports.

The project followed a structured software development process, covering requirements specification, system design, implementation, testing, and deployment.

## Roles & Responsibilities

### System Analysis
- Led requirements analysis activities with the system analyst team to identify and document stakeholder needs.
- Prepared system requirement documentation based on requirements gathering and stakeholder discussions.
- Translated business needs into functional requirements to guide system design and implementation.
- Collaborated with the development team to ensure the implemented features aligned with documented requirements.

### Software Testing
- Prepared and executed manual test scripts to verify application functionality against expected results.
- Tested user and administrator workflows, including product details, notifications, and other application features.
- Documented test scenarios, expected results, actual observations, and testing conclusions.
- Verified whether implemented features behaved as expected and supported the evaluation of system functionality.

## Key Features

### Customer Mobile Application
- User registration, login, and profile management.
- Product catalog, product details, search, and filtering.
- Shopping cart and favorites management.
- Checkout and recipient address management.
- Digital payment integration through Midtrans.
- Order status information and notifications.
- Communication between customers and the store owner.

### Admin Web Application
- Product and category management.
- Order management and status updates.
- Customer information management.
- Notifications and customer communication.
- Sales and order reporting.
